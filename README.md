# Completed RXDTDeploy Component

Готовый к использованию компонент по сборке\доставке разработки.

Этапы:
1. Проверка обязательных переменных.
2. Подготовка сервера к сборке\публикации.
3. Сборка пакета с автогенерируемым package.xml.
4. Публикация с помощью DeploymentTool на сервера СГ.

Обазательные переменные для использования компонента (Необходимо задать в ямле перед вызовом компоненты):
1. RXVERSION - версия RX (Примеру 4.10.0). Данная версия первоначально должна быть добавлена на сервер где крутится раннер
2. Repositories - список репозиториев в формате "[Work или Base] | [ssh путь до репы]".
Пример:
Repositories: 
    Work | ssh://git@git.starkovgrp.local:2224/golovnev/Test4.10Work.git,
    Base | ssh://git@git.starkovgrp.local:2224/golovnev/Test4.10Base.git
3. DeployIpServer - Ip сервера. (Пример 10.19.3.120)
4. DeployUserName - Логин пользователя от которого запускается публикация. (Пример Service User)
5. DeployUserPassword - Пароль пользователя от которого запускается публикация. (Пример 11111)

Переменные принимаемые через Input
1. StageCheckVariablesName - Наименования первого этапа (стандртно - Проверка переменных)
2. StagePreparedServerName - Наименование этапа подготовки сервера (стандртно - Подготовка сервера)
3. StageBuildPackageName - Наименование этапа сборки (стандртно - Сборка пакета)
4. StageDeployDTPackageName - Наименование этапа публикации (стандртно - Публикация (DT))
