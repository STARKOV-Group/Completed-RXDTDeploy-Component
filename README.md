# Completed RXDTDeploy Component

Готовый к использованию компонент по сборке\доставке разработки.

Этапы:
1. Проверка обязательных переменных.
2. Подготовка сервера к сборке\публикации.
3. Сборка пакета с автогенерируемым package.xml.
4. Публикация с помощью DeploymentTool на сервера СГ.

Обязательные переменные для использования компонента (Необходимо задать в ямле перед вызовом компоненты):  
1. `RXVERSION` - версия RX (Примеру 4.10). Данная версия первоначально должна быть добавлена на сервер где крутится раннер  
2. `Repositories` - список репозиториев в формате "[Work или Base] | [ssh путь до репы]".  
Пример:  
```yaml
Repositories: 
    Work | ssh://git@git.starkovgrp.local:2224/golovnev/Test4.10Work.git,
    Base | ssh://git@git.starkovgrp.local:2224/golovnev/Test4.10Base.git
```
В такой вариации система автоматом пытается подтянуть ветки с наименованием откуда был пуш. Если такой ветки в какой либо из реп нету то берёт дефолтную для репозитория  

Есть возможность указать для каждой репы свою репу - `Work | ssh://git@git.starkovgrp.local:2224/golovnev/Test4.10Work.git | master`  
В такой вариации вначале пытается захватить указанную ветку, если её нету то берёт дефолтную для репозитория  

3. `DeployIpServer` - Ip сервера. (Пример 10.19.3.120)
4. `DeployUserName` - Логин пользователя от которого запускается публикация. (Пример Service User)
5. `DeployUserPassword` - Пароль пользователя от которого запускается публикация. (Пример 11111)

Переменные принимаемые через Input
1. `StageCheckVariablesName` - Наименования первого этапа (стандртно - Проверка переменных)
2. `StagePreparedServerName` - Наименование этапа подготовки сервера (стандртно - Подготовка сервера)
3. `StageBuildPackageName` - Наименование этапа сборки (стандртно - Сборка пакета)
4. `StageDeployDTPackageName` - Наименование этапа публикации (стандртно - Публикация (DT))

Код для вставки в yaml проекта, для использования компоненты: 

```yaml
# Чекбокс "Expand variable reference" снимаем, возможно и "Protect variable"
variables:
  RXVERSION: "Версия RX"
  Repositories: 
    Список репозиториев в формате "[Work или Base] | [ssh путь до репы] | [Опционально ветку. Если не указать берёт одноименную с той что пушат, либо дефаолтную если первый вариант не найден]" 
  # Задавать желательно через переменные в настройках Ci_CD чтоб не хранить в открытом доступе. 
  DeployIpServer: "Ip сервера"   
  WebProtocol: "http или https, можно пропустить если стандартный http" 
  ServerHttpsPort: "Порт https, можно пропустить если стандартный 443"
  ServerHttpPort: "Порт http, можно пропустить если стандартный 80"
  DeployUserName: "Логин пользователя от которого запускается публикация"
  DeployUserPassword: "Пароль пользователя от которого запускается публикация"

include:
  - component: $CI_SERVER_FQDN/ci-cd-components/Completed-RXDTDeploy-Component/Completed-RXDTDeploy-Component@main
    inputs:
      rules: '$CI_COMMIT_BRANCH == "Test"' # Ограничение на срабатывание только по публикации в ветку Test  
      StageCheckVariablesName: Меняем наименование этапа
```
